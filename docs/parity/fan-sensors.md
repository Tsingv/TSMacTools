# Sensor inventory and provenance

The factual model/key/name/area tables in `FanSensorMetadata` were transcribed from zyvren/FanPilot `CatalogData.swift` at commit [`cb42bac0f6afdc5b119083887c0ea9a556818b5f`](https://github.com/zyvren/FanPilot/tree/cb42bac0f6afdc5b119083887c0ea9a556818b5f). The upstream MIT notice is retained in [FanPilot-LICENSE.txt](FanPilot-LICENSE.txt). The catalog covers 60 model identifiers sharing 36 tables. Exact-model rows use their recorded physical names; unknown-model heuristic rows deliberately use generic sensor labels and raw firmware keys.

The same revision's SensorClassifier, SensorCatalog, SensorPlanner, SMCSensorReader, HIDSensorReader, SensorEngine, SensorMonitor, Aggregates, and SensorTableView were inspected for behavior. Local Swift registry, classification, sampling, and AppKit presentation code implement the behavior independently. We deliberately decline its aggregate CPU fallback to SoC/everything: absent CPU remains unavailable.

Descriptors survive transient read failure for the reader lifetime. Values never survive into the next snapshot. All retained raw IDs stay selectable, including unavailable IDs and individual HID locations; logical product services deduplicate by maximum only for cards and aggregate contribution. Gas-gauge location IDs remain independently selectable and logical pack display uses the hottest gauge. No renumbering on a missing gauge can retarget a saved rule.

SMC discovery walks bounded firmware key counts (the transport's 16,384-key guard remains), checks float/sp78 widths, and includes T/ft/sd candidates. Tz*, TTPD, TVMD, TVmS and TfCB are excluded. Ordinary polls read the cached keys; wake, changed #KEY, or sixty seconds triggers inventory refresh. Private HID service reads remain optional and read-only; they are performed off-main once per poll and currently recreate their client, rather than caching private service objects across wake.

Meaningful curated cards include all observed catalog sensors, grouped by area; Other is hidden until requested and searchable by name, raw ID and source. The picker includes every discovered descriptor. Exact-model extras remain Other. Unknown families are bounded by physical hw.perflevel counts; GPU/memory heuristic families are limited to sixteen sensors. Missing topology does not manufacture CPU assignments. No generic Logic Board class is guessed from ambiguous firmware prefixes; a defensible catalog entry is required.

Validation: Xcode Debug build/test and Release build; Debug settings previews; Mos provenance guard; strict deep signature verification of both app configurations. New tests exercise type/width exclusions, topology bounds, exact catalog matching, retained descriptors with absent control values, fresh curated aggregates, lower/uppercase GPU families, HID logical maxima, and tdev/tcal exclusion. Device coverage beyond the current host, real wake recovery, sensor-to-physical-position validation, and legacy saved HID services whose LocationID changes across OS/firmware updates remain manual limits. No helper installation or hardware writes were performed.
